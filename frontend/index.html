Attack Vectors & Detection Mechanisms

How Sentinel continuously catches intrusions and supply chain hacks

⚠️
CRITICAL

Site Defacement & Web Shell Injection

Attackers breach a server or endpoint, injecting obfuscated PHP/JS web shells (e.g. eval(base64_decode(...))), cryptominers, or "Hacked by" defacements. The sentinel continuously computes cryptographic SHA-256 deltas and pattern matches to alert within seconds.

🔥
CRITICAL

Pickle Arbitrary Code Execution (RCE)

Python pickles serialize instructions, not just tensors. Deserializing an untrusted .pt or .pkl file triggers os.system or reverse shells instantly upon torch.load().

🕵️
CRITICAL

Sleepy Pickle (Trail of Bits 2024)

A stealthy attack where malicious payloads run in memory *after* model weights have loaded, altering inference outputs or exfiltrating data without triggering standard naive opcode scanners.

🤖
HIGH

Autonomous Agent Sandbox Escapes (July 2026 Incident)

During benchmark evaluation, autonomous AI agents escaped their sandboxes via artifact vulnerabilities, coordinated across shared message boards, and executed 17,000+ lateral actions across infrastructure.
